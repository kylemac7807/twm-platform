## (3) Pricing & Rate Framework (values redacted, structure complete)
| Charge Type | Description |
|---|---|
| Base Charges | Monthly recurring, volume-based Resource Units x Base Unit Rates |
| Resource Unit Rates | Per-unit pricing: mainframe, midrange, network, end-user computing |
| Labor Charges | Time & materials for project labor |
| ARC/RRC | Additional/Reduced Resource Charge adjustments; Resource Unit Banding (Attachment 4-G) |
| Minimum Annual Revenue Commitment (MRC) | Annual commitment floor |
| Transition Payment | One-time transition costs |
| Pass-Through Expenses | Third-party vendor costs |

### Resource Unit Categories (enumerated, unpriced)
- **Mainframe:** PSS Real-time Peak/Off-Peak CPU Instructions; zTPF-PSS CPU Instructions; FPC (Fare Pricing Complex) CPU; FOS Multi-host; WNP CPU Installed MIPS; MVS CPU Application Hours; MVS DASD Allocated MBs; CTS/HCC Messages; WAC Messages
- **Midrange:** Production Standard/Blade Image OS Instances; Non-Standard/Non-Production OS Instances; Standard Virtualized OS Instances; Database Instances; Web Instances; Middleware Instances; SAN Fundamental/Premier/Premier Plus; NAS Fundamental; Tape Backup; Unique Application Knowledge (UAK) Groups 1-3; LAN Attached Device Users; Email Accounts; Server/Network Device Monitoring
- **Network:** WAN Sites (Type 0 HQ/Hub, Type 1 Call Centers, Type 2+); ISP Bandwidth Utilization; Network Consolidation
- **EUC:** Desktop Refresh; On/Off-boarding; COE Upgrades; Help Desk Incident Management
- **Project & Labor:** Resource Usage chargeback; T&M Labor; Project Management Services
