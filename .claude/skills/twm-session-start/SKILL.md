# Session start

1. `git status`; read anything new or changed in `Claude outputs/` and `docs/`; commit Cowork's files as found so nothing changes silently.
2. Read `docs/action-items.md` (the single action list) and the latest decision-log rows in `docs/requirements-and-rationale.md`.
3. Check for files Kyle may have added (manual downloads in `corpus/`, a `.env`).
4. Run the tests; confirm they pass.
5. Tell Kyle in a few lines what arrived, what changed, and where we stopped. Then start where the action list says.
